# Student Planner (MVP v1.1)

Вебзастосунок для планування навчання, контролю дедлайнів та керування розкладом занять.

## Основний функціонал
- Реєстрація та авторизація користувачів.
- Керування тижневим розкладом занять із перевіркою конфліктів часу.
- Створення, редагування, видалення та відстеження статусу навчальних завдань.
- Фільтрація завдань за предметами та сортування за дедлайнами.

## Запуск та тестування
1. Відкрийте `index.html` у браузері або запустіть локальний сервер (`node server/server.js`).
2. Для запуску модульних тестів виконайте команду:
   ```bash
   node --test
